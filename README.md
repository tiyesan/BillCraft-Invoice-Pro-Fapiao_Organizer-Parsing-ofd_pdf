一、软件简介
1.1 软件定位
票匠 Pro 5.0 是一款面向财务人员、报销人员及企事业单位开发的智能电子票据整理工具。
软件针对日常财务工作中：
电子发票数量多
PDF/OFD格式混杂
铁路票、航空行程单、发票需要分类整理
报销附件需要打印成A4格式
多页票据容易排序混乱
等实际问题设计。
软件能够自动识别电子票据类型，将不同格式文件转换为统一图片格式，并按照财务报销习惯进行自动排版，最终生成规范的合并PDF文件。

二、主要功能
2.1 自动票据分类
软件支持：
类型	支持格式
增值税发票	PDF、OFD
铁路电子客票	PDF、OFD
航空运输电子客票行程单	PDF、OFD
软件自动扫描用户选择的目录，根据票据内容及文件特征进行分类。

2.2 PDF/OFD转换
支持：
普通PDF电子发票
数电票PDF
OFD电子发票
自动转换为高清PNG临时文件，用于统一排版。
特点：
保留原始票面
支持多页PDF
支持OFD电子签章文件

2.3 铁路电子客票整理
铁路票采用固定尺寸排版：
每张约8.5cm × 6.925cm
A4页面双列排列
自动分页
适用于：
火车票打印
出差报销附件整理

2.4 航空运输电子客票行程单整理
自动识别：
航空运输电子客票行程单
排版规则：
A4单列排列
保持比例缩放
自动分页

2.5 增值税发票整理
发票采用：
A4宽度适配
保持原始比例
自动上下排列
支持：
单页发票

七、注意事项

7.1 不要打开正在处理的文件
处理过程中：
不要移动：
PDF文件
OFD文件
输出目录
否则可能导致转换失败。

7.2 OFD文件处理时间较长
OFD格式包含：
XML结构
数字签章
字体资源
转换时间通常比PDF长。
大型OFD：
可能需要几十秒。

7.3 多页PDF建议保持完整
不要手工拆分页。
例如：
正确：
合同发票.pdf
错误：
合同发票第一页.pdf
合同发票第二页.pdf
软件会自动处理分页。
