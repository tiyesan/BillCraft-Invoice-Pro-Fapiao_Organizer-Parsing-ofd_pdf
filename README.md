票匠BillCraft invoice Pro软件简介
票匠BillCraft invoice Pro 是一款面向财务报销、审计归档及行政办公场景开发的智能电子票据处理软件，专注解决 PDF/OFD电子票据格式混杂、票据分类繁琐、多页文件排序混乱、A4打印排版效率低 等实际问题。

软件支持增值税电子发票、铁路电子客票、航空运输电子客票行程单等多种主流电子票据格式，可自动完成智能识别、分类整理、PDF/OFD高清转换、A4自动拼版、多页票据顺序优化及一键生成标准报销附件，显著提升财务资料整理效率。

区别于传统PDF合并工具，票匠 Pro 深度结合国内企事业单位财务报销业务流程进行设计，采用专业票据版式算法，在保证票据完整性、清晰度及打印规范性的同时，实现多类型票据的智能统一管理。

## BillCraft Invoice Pro 5.2 —— 新增智能票据解析功能

BillCraft Invoice Pro 5.2 在原有票据批量整理与合并功能的基础上，新增了 **电子票据智能解析功能**。

软件可对用户导入的原始 PDF、OFD 电子票据进行自动识别与文本解析，并根据票据内容自动判断票据类型，提取原始票据文本信息，生成统一的票据解析结果文件。

### 核心功能

* 支持 PDF 电子票据解析
* 支持 OFD 电子票据解析
* 自动识别增值税电子发票
* 自动识别铁路电子客票
* 自动识别航空运输电子客票行程单
* 自动提取票据原始文本内容
* 自动记录票据来源文件路径
* 批量解析多个文件及目录
* 自动生成《发票解析结果.xlsx》
* 与票据合并功能同步执行，实现“一次导入、自动整理、自动解析”

### 支持的票据格式

| 文件格式        | 支持情况 |
| ----------- | ---- |
| PDF         | ✓    |
| OFD         | ✓    |
| 增值税电子发票     | ✓    |
| 铁路电子客票      | ✓    |
| 航空运输电子客票行程单 | ✓    |

### 工作流程

```text
导入票据文件
      ↓
自动扫描文件目录
      ↓
识别 PDF / OFD 格式
      ↓
提取票据原始文本
      ↓
自动判断票据类型
      ↓
生成票据解析数据
      ↓
自动输出 Excel
      ↓
同步生成合并票据 PDF
```

### 输出结果

完成处理后，软件将在用户选择的目录中自动生成：

* `合并票据.pdf`
* `发票解析结果.xlsx`

其中，《发票解析结果.xlsx》用于集中保存每张票据的来源文件及解析出的原始文本信息，便于后续进行人工核查、数据整理和财务报销处理。

### 技术特点

BillCraft Invoice Pro 5.2 优先针对原始电子票据进行文本解析，不依赖第三方云端 OCR 服务，无需配置 API Key，也不会产生额外的识别调用费用。

相比传统 OCR 图片识别方式，直接解析原始 PDF/OFD 电子票据能够更好地保留票据原始文本信息，并减少因图片清晰度、扫描质量等因素造成的识别误差。

BillCraft Invoice Pro 5.2 实现了从：

> **票据批量整理 → 格式转换 → PDF 合并**

进一步升级为：

> **票据批量整理 → 智能解析 → 数据导出 → PDF 合并**

使票据处理不仅停留在“文件整理”层面，同时具备了基础的数据提取与结构化处理能力。
